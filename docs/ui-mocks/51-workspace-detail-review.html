進め方の提案

最初：採用済みサイドバーA、保存ボタンの文言、通常のツリー案内、フッター。意味を変えずに、違和感を取りやすい。

次：レビュー欄と検索の重複整理。未読・下書き・同名ファイル・空・エラーの状態をStorybookで確認。

比較して決める：本文の枠、Source切替、プレビュー表現、インスペクターの常設。見た目と発見性のトレードオフがある。
