What if Vivi only reviewed documents?

The useful cut is not “hide code extensions.” It is to make every visible object a document with structure, rendered meaning, semantic change, and anchored feedback. Assets may support a document without becoming review destinations of their own.

TodayLocal workspace review across every artifact
→
Sharper promiseRead and review agent-written documents before they ship

Vivi remains familiar, but only documents enter the tree, tabs, search, and Review Queue.

We want a reversible product cut and fast validation with existing architecture.

Can feel like the current product with an extension allow-list.
