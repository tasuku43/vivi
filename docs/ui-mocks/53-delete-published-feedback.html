実装時に守る動作の提案

削除の単位公開済みの人間のコメント1件。Unseen／Seenどちらも対象。同じスレッドやファイルの他のコメントは保持する。
エージェントへの反映削除後のinbox、文書コメント、エクスポートから除外する。すでに取得済みの内容や進行中のエージェントの作業は取り消せない。
Attention残っている未読・下書き・入力・Recentから再計算。削除を新しい閲覧や活動として記録して固定表示を延長しない。
同期と保存再読込や別のブラウザーでも復活しない。古い取得結果で削除済みコメントが戻らないようにする。削除の保存方式はWired Featureで決定する。
確認とフォーカス確認中は対象本文を残す。キャンセル時はDeleteへ戻る。最後のコメントが消えたら文書へフォーカスを戻し、成功・失敗を通知する。
未解決の入口元ファイルが消えたコメントは文書内から開けない。まずAで通常の文書内削除を定義し、Unavailable feedbackからの管理が必要ならCの入口を追加する。
Review stage: HTML Concept Mock → Storybook Facade → Wired Feature. 入口Aは選択済みです。Storybook「Review/Published Comment Deletion」で操作をレビューできます。実際の削除APIにはまだ接続していません。
