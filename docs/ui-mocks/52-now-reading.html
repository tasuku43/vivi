01 / 分類を選ばなくていい

上にフィードバック、下に最近の動き。一つのファイルは一度だけ表示し、ここにある理由を短い言葉で添えます。未読と下書きは、時間で隠しません。

02 / 起動前の作業も見える

Gitの差分と更新時刻、直近のコミットから、起動前30分の文書更新を復元。古い差分や、内容が変わらない読み込みでは時間を延ばしません。

03 / 見終えたら、静かに退く

最近の項目は30分で退きます。「×」で今だけ隠すことも可能。次の更新・明示的なオープンで戻ります。開いている文書と左のツリーはそのままです。
