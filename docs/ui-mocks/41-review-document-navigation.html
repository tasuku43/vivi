Vivi · Inspector navigation study

Review is home. Document is context.

Four ways to move between the review queue and the active document without making them look like two unrelated buttons. Every concept keeps Review as the default, preserves queue position when inspecting a document, and separates navigation from the “Next queued” workflow action.

State model Review queue → open work item → read/comment in document → return to the same queue position → next item

A. Stable workspace tabs

Use the entire inspector header as two stable destinations. Mode never changes its label or location.
