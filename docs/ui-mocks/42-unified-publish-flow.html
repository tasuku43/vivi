Vivi · Publish experience study

One comment lifecycle, in both inspector surfaces.

Review Queue and Document should not invent different meanings for the same private feedback. These concepts keep the lifecycle fixed, then vary only where the final Publish decision lives.

1 · Typing Browser-local input. Recoverable, but excluded from Publish.
2 · Ready Saved private feedback. Counted and ready to Publish.
3 · Open Published feedback. Agent-visible and now in review.
Invariant across every concept

Save moves Typing to Ready. Publish moves Ready to Open. Typing is never silently included, and Publish does not imply that an agent has already read the thread.

The current mismatch to remove

No more “Publish pending” in one surface and “Publish 4 comments” in another. Scope, count, status color, and CTA order should remain recognizable when the inspector tab changes.

A · Draft panel B · Publish bar C · Review gate

A · Shared draft panel

Use one reusable Ready-to-publish panel in both surfaces. Review shows workspace scope; Document shows current-document scope. The internal state order and actions stay identical.
