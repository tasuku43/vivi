VIVI / CONCEPT 50

選択は、いま読んでいる1行に。

親フォルダーの面強調と OPEN 表示を外し、文書名とH1に場所を戻す。

ファイルをクリックして3案を同時に比較。Tabでフォーカスも確認。

A · 1行の面 おすすめ

選択したファイルだけ、穏やかな背景色で示す。
親フォルダーは通常表示に戻す。

文書を探すための、静かなツリー

読みやすさを優先。選択範囲が一目で分かる。配色が淡いテーマでは、背景のコントラストが要になる。

B · 短い左マーカー

薄い背景＋選択行だけに短いアクセント線。
現在の左線の文法を整理して残す。

選択位置を、視線の端で見つける

見つけやすさを優先。長い一覧でも選択位置が目に入る。階層の縦線と選択マーカーの2種類の線が残る。

C · 枝と文字

背景は付けず、ファイル名と直近の縦線を強調。
親はアイコンの色だけで経路を添える。

階層の中の現在地を、軽く示す

軽さと経路を優先。最も静か。ただし色への依存が強く、行全体の選択範囲はA/Bより分かりにくい。

3案に共通する整理

選択 ≠ 開いているタブ

選択は1行。別タブで開いているファイルには小さな中立色の点だけ。OPEN・open tab の補足行は表示しない。

親フォルダー ≠ 選択

展開中の親に面強調は付けない。選択行を隠すまで折りたたんだ時だけ、フォルダー右端に小さな現在地の点を出す。

ホバー ≠ フォーカス

ホバーは薄い背景、キーボードフォーカスは細い輪郭線。選択やホバーによって行の高さを変えない。

HTMLコンセプト比較。フォルダーアイコン＋階層の縦線、ファイル名＋H1の順序は採用済みの方向を継続。レビュー・未読の表示体系は今回の比較対象外。
