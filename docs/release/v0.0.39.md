# v0.0.39 — Fetch unseen feedback

- Add `vivi inbox <url> --read-as codex|claude --unseen` to retrieve only
  feedback unseen by the selected actor and record receipts for returned threads.
- Human follow-ups make a thread eligible again. Returned threads preserve
  their full conversation and anchor context. Existing full-snapshot reads
  remain available by omitting `--unseen`.
- Update Codex and Claude plugins to 0.2.1. Apply-feedback uses unseen retrieval
  for its initial fetch and bounded refresh, with full retrieval for resuming
  interrupted work. Inspection-only reads stay passive.

The unseen filter requires both the CLI and running server from v0.0.39 or
later. Plugin installation does not upgrade the Vivi binary; restart older
servers after upgrading.
